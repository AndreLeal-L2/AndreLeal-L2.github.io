# AraraWeb

Site institucional da AraraWeb publicado a partir do repositorio `AndreLeal-L2.github.io`.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Desenvolvimento

Requisitos:

- Node.js
- npm

Instale dependencias:

```bash
npm install
```

Inicie o ambiente local:

```bash
npm run dev
```

## Scripts

| Comando | Descricao |
| --- | --- |
| `npm run dev` | Inicia o servidor de desenvolvimento Next.js. |
| `npm run build` | Gera o build de producao. |
| `npm run start` | Executa o servidor de producao apos o build. |

## Estrutura

- `src/`: codigo principal da aplicacao.
- `public/`: assets estaticos.
- `next.config.js`: configuracao do Next.js.
- `tailwind.config.js`: configuracao do Tailwind CSS.

## Deploy

Este repositorio pode ser publicado pelo GitHub Pages ou por uma plataforma compativel com Next.js, conforme a configuracao de deploy ativa.
